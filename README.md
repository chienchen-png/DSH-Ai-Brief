# AI 新闻推送（Aurabot 模块）

> 一个给 QQ 机器人用的「新闻三连」模块：**早报 / 午报 / 晚报**，自动抓取、筛选、总结并推送到群里。

- 作者：[@chienchen-png](https://github.com/chienchen-png)
- 仓库：https://github.com/chienchen-png/Product-DSH-Ai-brief
- 模块市场：在 Aurabot 面板「市场」里搜 **AI 新闻推送** 即可安装

---

## 功能

| 节点 | 默认时间 | 内容 |
|---|---|---|
| 🌅 早报 | 09:31 | AI 资讯：**知乎热榜 + 全网热榜**（微博/抖音/头条），Bing 默认关闭 |
| 🌤 午报 · 论坛速报 | 12:30 | 腾讯频道论坛热帖：抓前 10、按浏览/评论排序、总结 4 条 |
| 🌙 晚报 | 21:30 | 同早报（查询词、条数独立配置） |

特点：

- 数据源：知乎热榜（30 条）+ 全网热榜（微博热搜/知乎热榜/抖音热点/今日头条，共 100+ 条），Bing 留空即不用
- **三节点独立开关、时间、条数**，互不影响
- 群里直接发「早报」「晚报」「论坛速报」也能要一份：**早报/晚报当天固定**，**论坛速报现抓最新热帖**
- **论坛搜索**：群友说「翻翻论坛找 XX」，她会调 orum_search 翻信息流、按关键词匹配并打开命中帖子补全
- 每条：`序号.【中文标签】标题` + 一句吐槽 + 完整链接
- 标签：模型 / 应用 / 财报 / 融资 / 政策 / 芯片 / 人物 / 热点（论坛：校园 / 生活 / 吐槽 / 情感 / 消费 / 学习 / 热点 / 求助）
- 面板顶部三张状态卡：今天发没发、下次时间、一键预览 / 发我
- 午报用本机 Edge/Chrome 以游客身份只读论坛，**不需要登录**
- 抓取失败/页面改版 → 记日志、不发空消息；模型失败 → 用原始标题兜底

## 安装

### 方式一：模块市场（推荐）

Aurabot 面板 → 市场 → 搜索 **AI 新闻推送** → 安装 → 在「已安装」里打开面板配置。

### 方式二：一句话让 AI 部署

把下面这段复制给 DSH / 任意 AI：

```
帮我在 Aurabot 里安装「AI 新闻推送」模块（模块 id: ai-brief）：
1. 从模块市场安装，或把 index.mjs / panel.js / module.json 复制到模块目录；
2. 早报 09:31、晚报 21:30 保持默认，条数各 5；
3. 午报默认关闭；
4. 装好后在面板里给我看一眼状态卡，再发一条早报预览给我确认。
```

更多部署话术见 [`deploy-prompt.txt`](./deploy-prompt.txt)。

## 配置

面板分四个页签：

- **早报 / 晚报**：开关、时间、条数、Bing 查询词、表情包、「早报来了」提示
- **午报**：开关、时间、论坛地址、候选条数、发送条数、无头模式、调试端口
- **共享设置**：总开关、RSS 源、媒体/热榜关键词、热榜节点、AI 提示词、短链开关

> 论坛地址填你自己的腾讯频道论坛页，例如 `https://pd.qq.com/g/<频道>/`；不启用午报就完全不会启动浏览器。

## 数据与隐私

模块会访问：

- `https://www.bing.com/news/search`（RSS）
- `https://api.zhihu.com/topstory/hot-lists`（热榜）
- 你填写的论坛地址（只读公开页面，游客身份）
- 可选：`is.gd` / `tinyurl.com`（仅当你开启短链）

**不会**上传 Cookie、聊天记录或任何账号信息；抓到的内容只用于生成本群简报。午报可在面板一键关闭。

## 开发

```
ai-brief/
├── index.mjs      # 模块入口：定时、路由、抓取、总结、发送
├── panel.js       # 面板 UI（React 运行时，无构建）
├── module.json
├── README.md
└── LICENSE
```

环境：Node.js ≥ 22.2（用到了内置 `WebSocket` / `fetch`），Aurabot 插件 ≥ 1.2.0。
午报需要本机安装 Edge 或 Chrome（自动探测常见路径）。

自测：面板「午报」页可直接点「预览」；不启用午报时不影响早/晚报。
