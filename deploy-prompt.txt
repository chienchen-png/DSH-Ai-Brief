# 「AI 新闻推送」一句话部署话术

把下面任意一段复制给 DSH（或任意能操作 Aurabot 的 AI），它就能帮你装好。

## 1. 最小安装 + 默认配置

```
帮我在 Aurabot 里安装「AI 新闻推送」模块（id: ai-brief）：
- 从模块市场搜索安装，或把 index.mjs / panel.js / module.json 放进模块目录后重新加载；
- 早报 09:31、晚报 21:30，条数各 5；
- 午报先不开；
- 装好后发一条早报预览给我看。
```

## 2. 要论坛速报

```
在「AI 新闻推送」里开启午报：时间 12:30，论坛地址填 https://pd.qq.com/g/<你的频道>/ ，抓 10 条候选、发 4 条；用无头浏览器；先预览一次给我确认，再打开定时。
```

## 3. 只想每天要一条早报

```
安装「AI 新闻推送」，只开早报：时间 08:30，条数 5，发到当前群；午报和晚报都关掉。
```

## 4. 换内容源

```
在「AI 新闻推送 → 共享设置」里把媒体源换成我给的 RSS 列表，关键词改成……；早报查询词保留 Bing 默认。
```
